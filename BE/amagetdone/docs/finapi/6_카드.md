#### 2.8.2 가맹점 등록[¶](https://project.ssafy.com/docs/ssafy-finance/api-credit-card#282 "Permanent link")

##### 설명[¶](https://project.ssafy.com/docs/ssafy-finance/api-credit-card#_7 "Permanent link")

카테고리 조회 후 가맹점을 등록합니다.  
카테고리 하위로 다양한 가맹점을 생성할 수 있으며,  
추후 등록된 가맹점 목록 내에서 카드 결제를 할 수 있습니다.  
가맹점 목록 조회 API를 통해 샘플 데이터를 참고하여 가맹점을 등록할 수 있습니다.

##### 요청 메시지 URL[¶](https://project.ssafy.com/docs/ssafy-finance/api-credit-card#url_1 "Permanent link")

| HTTP URL | HTTP Method |
| --- | --- |
| `https://finopenapi.ssafy.io/ssafy/api/v1/edu/creditCard/createMerchant` | POST |

##### 요청 메시지 명세[¶](https://project.ssafy.com/docs/ssafy-finance/api-credit-card#_8 "Permanent link")

| Header | 공통 |  |  | Y | `userKey` 제외 |
| categoryId | 카테고리ID | String | 20 | Y |  |
| merchantName | 가맹점명 | String | 100 | Y | 카테고리에 맞는 가맹점명 입력 (ex. 이마트, 에쓰오일, 지하철 등) |
