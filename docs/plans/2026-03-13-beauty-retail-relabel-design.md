# Beauty Retail Relabel Design

## Context

`merchant_info` 약라벨을 확인한 결과 `미용`은 미용실, 피부관리, 네일, 마사지, 사우나 중심으로 매핑되어 있습니다. 반면 현재 gold dataset의 `미용` 샘플에는 `올리브영`, `미샤`, `랄라블라` 같은 화장품 리테일 브랜드가 다수 포함되어 있어 라벨 의미가 서로 충돌합니다.

이 충돌 때문에 학습 시에는 `미용 = 서비스업`, 평가 시에는 `미용 = 화장품 리테일`처럼 받아들여질 수 있고, 실제로 `미용` 성능 저하가 발생했습니다.

## Decision

gold dataset의 `미용` 라벨 중 화장품 리테일 계열은 `쇼핑/패션`으로 재라벨링합니다.

범위는 다음과 같습니다.

- 대상 파일: `AI/lab/data/merchant_category_dataset_v1/train.csv`, `valid.csv`, `test.csv`
- 대상 행: 현재 `category_name == '미용'` 인 행
- 이동 라벨: `category_id = 9`, `category_name = '쇼핑/패션'`

## Relabel Rule

화장품 리테일 계열은 상호명 기반 규칙으로 판별합니다.

포함 신호:

- 주요 브랜드: `올리브영`, `씨제이올리브영`, `랄라블라`, `롭스`, `미샤`, `아리따움`, `토니모리`, `이니스프리`, `네이처리퍼블릭`, `더페이스샵`, `스킨푸드`, `에뛰드`, `홀리카홀리카`, `클리오`, `롬앤`, `오휘`, `후`, `숨`, `닥터지`
- 일반 리테일 표현: `화장품`, `코스메틱`, `뷰티스토어`, `뷰티샵`

제외 신호:

- 서비스업 표현: `미용실`, `헤어`, `네일`, `피부관리`, `에스테틱`, `왁싱`, `속눈썹`, `마사지`, `안마`, `사우나`, `목욕`

즉, 리테일 신호가 있고 서비스업 신호가 없을 때만 `쇼핑/패션`으로 이동합니다.

## Safety

- 기존 `쇼핑/패션` 데이터는 건드리지 않습니다.
- `미용`이지만 실제 서비스업으로 보이는 텍스트는 그대로 유지합니다.
- 변경 전후 건수와 대표 샘플을 기록합니다.

## Verification

- 회귀 테스트로 대표 브랜드가 `쇼핑/패션`으로 이동하는지 확인
- 서비스업 예시는 그대로 `미용`에 남는지 확인
- 적용 후 `train/valid/test`에서 변경 건수와 라벨 분포를 점검
