# Mock API Samples

This folder stores frontend mock responses shaped like the backend API.

Files:
- `plans_get.json`: `GET /v1/plans`
- `plans_post.json`: `POST /v1/plans`
- `plans_patch_priority.json`: `PATCH /v1/plans/priority`
- `plans_detail_17.json`: `GET /v1/plans/17`
- `plans_weekly_plans_17_page0_size5.json`: `GET /v1/plans/17/weekly-plans?page=0&size=5`
- `plans_video_download_success.json`: `GET /plans/{planId}/video/download` success sample
- `plans_video_download_not_found.json`: `GET /plans/{planId}/video/download` error sample
